# Automated Resume Screening Tool

## Overview
Short explanation of the system.

## Features
- Resume upload (PDF/DOCX)
- NLP parsing
- TF-IDF + cosine similarity ranking
- Explainable scoring (top terms)

## Tech Stack
- React
- Node.js + Express
- SQLite
- Python (scikit-learn)

## Installation

### Backend
cd backend
npm install
python -m pip install -r python/requirements.txt
node server.js

### Frontend
cd frontend
npm install
npm run dev
